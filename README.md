# WindowMaster — Window Layout Anchor & Monitor Wake Engine

WindowMaster is a lightweight, adaptive utility designed to restore window positions after monitor sleep, wake, or resolution changes.  
It is built for multi‑monitor setups, HDMI/DP displays, and systems where windows jump or resize incorrectly after waking.

## ✨ Features

- Adaptive or manual restore modes  
- Automatic snapshotting of window positions  
- Reliable restore after monitor wake  
- Multi‑monitor support  
- Per‑user configuration  
- Scheduled task integration  
- Diagnostic tools  

## 🚀 Installation
Save the latest ZIP file to your Computer.
Extract the folder to a suitable location
i.e. C:\WindowMaster(latest)
Then run the WindowMaster EXE file.

## 🛠️ Requirements

- Windows 10 or 11  


## 🧪 Diagnostics

The installer and engine both include built‑in diagnostics to help troubleshoot:

- Monitor detection  
- Power timeout analysis  
- Snapshot/restore logs  
- Engine activity logs
